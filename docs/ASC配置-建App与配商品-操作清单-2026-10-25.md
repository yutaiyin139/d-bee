## 一、前置：注册 Bundle ID（developer.apple.com）

如果 `cn.com.dbee.app` 还没在 Apple Developer 后台注册过：

1. 登录 [developer.apple.com](https://developer.apple.com) → **Certificates, Identifiers & Profiles** → **Identifiers** → 点 **+**。
2. 选 **App IDs** → **App**。
3. **Description**：`D-Bee`；**Bundle ID** 选 **Explicit**，填 `cn.com.dbee.app`。
4. **Capabilities**：勾选 **In-App Purchase**（其余如 Push Notifications 按需，本期可不勾）。
5. 注册完成后回到 App Store Connect 才能选到这个 Bundle ID。

---

## 二、建 App（App Store Connect）

1. 登录 [appstoreconnect.apple.com](https://appstoreconnect.apple.com) → **我的 App** → 点 **+** → **新建 App**。
2. 逐项填写：

| 字段 | 值 |
|---|---|
| 平台 | **iOS** |
| 名称 | `自律蜜蜂`（中文区显示名；⚠️ 须与**软著登记名称**完全一致，国内安卓商店强制） |
| 主要语言 | **简体中文** |
| Bundle ID | 选 `cn.com.dbee.app` |
| SKU | `dbee_ios_001`（自定，内部唯一即可） |
| 用户访问权限 | 完全访问（个人账号默认） |

3. 建好后进入 App 详情页，**先不填** ICP 备案号（待备案下来再补）——备案号字段中国区必填，但**提审前补上即可，不阻塞建 App 和配商品**。

## 三、建订阅组 + 2 个订阅商品（月 / 年）

1. App 详情页左侧 **「货币化」→「订阅」**（或「App 内购买项目」里的订阅分类）。
2. 点 **创建订阅组**（如首次）：
   - **Reference Name**：`D-Bee Pro`（内部参考名，用户不可见）
3. 在订阅组内点 **创建订阅**，逐个建：

**商品 A —— 月订阅**
| 字段 | 值 |
|---|---|
| 类型 | 自动续期订阅（Auto-Renewable Subscription） |
| 参考名（Reference Name） | `月订阅` |
| **商品 ID（Product ID）** | `dbee_pro_monthly` |
| 订阅期时长 | **1 个月** |
| 价格 | ¥18（中国区选对应价格点或自定义价格 18） |
| 免费试用 / 推介促销 | 本期不启用 |

**商品 B —— 年订阅**
| 字段 | 值 |
|---|---|
| 类型 | 自动续期订阅 |
| 参考名 | `年订阅` |
| **商品 ID** | `dbee_pro_yearly` |
| 订阅期时长 | **1 年** |
| 价格 | ¥128 |
| 免费试用 / 推介促销 | 不启用 |

4. **订阅组内等级（Level）**：月、年都保持 **Level 1**（同一等级，用户可在月/年之间自由切换升级/降级）。

## 五、每个商品的审核信息（截图 + 描述）

每个商品都要补「审核信息」（App Review Information），否则商品状态不会变「已准备好提交」：

- **审核截图（Review Screenshot）**：上传**付费墙实际 UI 截图**（要显示商品价格）。按 ASC 页面提示的尺寸/格式上传（通常是 iPhone 截图规格）。⚠️ 截图内容须与线上 UI 一致（3.1.2 相关：付费墙要能显示商店价格）。
- **描述**（本地化）：
  - 月订阅：`解锁全部 Pro 功能：AI 拍照识别不限次、AI 问答不限流、饮食报告扩展、数据导出。按月自动续费，可随时取消。`
  - 年订阅：`解锁全部 Pro 功能，按年订阅更划算（约 ¥10.7/月）。自动续费，可随时取消。`
  - 终身买断：`一次性买断，永久解锁全部 Pro 功能，无需续费。`

## 六、生成 App 专用共享密钥（Shared Secret）

1. App 详情页左侧 **「通用」→「App 信息」→「App 专用共享密钥」**（或「App 内购买项目」页顶部的共享密钥入口）。
2. 点 **管理** → **生成**，复制生成的主共享密钥字符串。
3. 该密钥配到服务器 `/etc/dbee/gateway.env` 的 `APPLE_SHARED_SECRET`（配合已落地的 0037 迁移 + 网关 `APPLE_*` env，见 `收费模块-前置条件待办清单.md` 1.7/1.8）。
4. ⚠️ 密钥**只存服务器 env，不入库、不入 git**；泄露需在 ASC 重新生成。

## 七、常见坑（务必避开）

1. **商品 ID 不可改**——创建前逐字符核对，错一个字母就只能删了重建（删除会留记录，审核时难看）。
2. **月/年必须同一订阅组**——放不同组会导致用户无法在月/年之间升降级，也违反 3.1.2 订阅语义。
3. **价格与代码/文案一致**——付费墙 `PRICE_TAG` 写死 ¥18/¥128/¥298，ASC 定价必须对齐（iOS 端已优先展示商店本地化价，但硬编码是回退，两者不能打架）。
4. **订阅商品 ≠ 非消耗型**——`dbee_lifetime` 必须是**非消耗型**，不是订阅；放错类型会导致买断逻辑对不上（代码 `plan: 'lifetime'`）。
5. **共享密钥 vs 服务端密钥**——ASC 的「App 专用共享密钥」是给服务端验签用的；不要和「App Store Connect API 密钥」混淆（那是团队密钥，用途不同）。
6. **备案号字段**——建 App 时中国区会看到 ICP 备案号字段，**留空先不填**，备案下来后补，不阻塞本清单。
