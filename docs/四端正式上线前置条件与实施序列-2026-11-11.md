## 七、红线

- 🔴🔴 **`deploy-gateway.sh` 是全站永久锁死级地雷**：缺 `IDENT_PEPPER` 即重置 → 全站身份永久失效；**只读 / 备份也绝不跑**，网关变更一律手术式脚本。
- 🔴🔴 **铁律 #13**：「已完成」必须附生产侧实测证据。
- 🔴 **真机调试 ≠ 体验版**（调试会话注入 Web API，会掩盖 JSCore 缺口）。
- 🔴 **门控与实装必须同批**：只展示价格却必然支付失败 ＝《广告法》第 4 条虚假宣传。
- 🔴 **xpay 资损**：推送丢失补权益后**必须调 `/xpay/notify_provide_goods`**（否则资金不结算）；已扣款未确认一律 `settling`，**绝不报 error**；`signData` 原样透传；道具直购**不自动续费**；provider 必须 `'wechat_xpay'`。
- 🔴 兑换码核验只用库内 sha256 比对，**绝不调 `redeem_by_code`**。
- 🔴 原生包禁用 `npm run build`；`build:web` 会删 `dist/legal/`；native 与 web 共用 `dist/`，部署 web 前必须重跑 `npm run build` 并比对入口 js 文件名。
- 🔴 法律公示公开信息真相源在 `packages/shared`，不得只放 `.env`。
