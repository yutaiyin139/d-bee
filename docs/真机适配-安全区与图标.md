# 真机适配：状态栏安全区与 App 图标修复

- 日期：2026-10-14
- 触发：小米 15 Ultra 真机反馈两个问题
- 状态：**两个问题均已修复并在 Android 模拟器复验通过**

---

## 问题 1：内容顶到状态栏（与手机时间间距过小）

### 现象

App 头部「自律蜜蜂」直接顶在状态栏时钟下方，几乎没有间距。

### 根因

- Android 15（targetSdk 35）**强制 edge-to-edge**，WebView 内容延伸到状态栏底下；
- 工程内已有 `.page-top { height: env(safe-area-inset-top) }` 占位，但**部分安卓 WebView
  （小米 15 Ultra 实测）`env(safe-area-inset-*)` 返回 0**，占位高度为 0，等于没适配；
- Capacitor 8 内置 `SystemBars` 插件（`@capacitor/android`）的真实做法是：把原生 insets
  以 **CSS 自定义属性** `--safe-area-inset-top` 等注入到 `<html>` 元素上
  （源码 `SystemBars.injectSafeAreaCSS`），与 `env()` 是两条独立通道。

### 修复

`src/styles.css` 全部 8 处统一改为「**变量优先、env 兜底**」：

```css
height: var(--safe-area-inset-top, env(safe-area-inset-top));
padding: 0 18px calc(96px + var(--safe-area-inset-bottom, env(safe-area-inset-bottom)));
```

两条通道都覆盖：

| 环境 | 变量 | env() | 结果 |
|---|---|---|---|
| Android 原生（Capacitor 8） | SystemBars 注入 ✅ | 可能失效 | 用变量，精确像素 |
| iOS 原生 | 不注入 | WebView 支持 ✅ | 落到 env()，行为不变 |
| Web / PWA | 不注入 | 浏览器支持 ✅ | 落到 env()，行为不变 |

### 复验

模拟器（Android 17）实测：标题与状态栏时钟之间恢复正常间距。
证据：`docs/verify/phase1-05-safearea-fixed.png`。

## 问题 2：桌面图标显示的是 Capacitor 默认图标

### 根因

`cap add android` 生成的是 Capacitor 默认图标资源，从未被替换过：
`android/app/src/main/res/mipmap-*/ic_launcher*.png`、`ic_launcher_foreground.png`
（自适应图标前景）以及 `values/ic_launcher_background.xml`（#FFFFFF）。

### 修复

新增 `tools/gen-app-icons.py`（Pillow，可重复执行）：

| 产物 | 来源 | 尺寸 |
|---|---|---|
| `mipmap-*/ic_launcher.png` | `public/icon-512.png` | 48/72/96/144/192 px |
| `mipmap-*/ic_launcher_round.png` | 同上 + 圆形蒙版 | 同上 |
| `mipmap-*/ic_launcher_foreground.png` | `public/icon-maskable-512.png` | 108/162/216/324/432 px |
| `values/ic_launcher_background.xml` | 改为品牌底色 `#FBF8F1` | — |
| iOS `AppIcon.appiconset/AppIcon-512@2x.png` | `public/icon-512.png` | 1024×1024（RGB 无透明） |

自适应图标结构（`mipmap-anydpi-v26/ic_launcher.xml`）无需改动，
前景替换后所有 Android 8+ 启动器都会按新图渲染。

### 复验

应用信息页显示金色「D + 蜜蜂」图标，非默认 Capacitor 图标。
证据：`docs/verify/phase1-06-appicon.png`。
另经字节比对确认新图标已进包（`res/mipmap-xxxhdpi-v4/ic_launcher.png` 与源文件逐字节一致）。

## 出包与升级注意

```bash
# 图标变更后重新出包
python tools/gen-app-icons.py     # 仅图标源变化时需要
npm run native:sync               # build + cap sync
cd android && ./gradlew assembleDebug
```

1. **真机升级**：覆盖安装（`adb install -r`）后若桌面图标仍旧，是启动器缓存，
   重启手机或清除启动器缓存即可，不是包的问题。
2. **iOS 侧**：图标文件已替换，等 Mac mini 上 Xcode 构建时自然生效。
3. 本轮顺手的环境教训：XML 注释里不能出现 `--`（`<!-- ... --bg ... -->` 会让资源合并直接失败）。
