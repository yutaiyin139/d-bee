## 一、目标流程与合规依据

```
[Web d-bee.cn]  仅展示三档定价（不收款、不下单、不创建订单）
      │  点「去微信小程序下单」/ 扫码
      ▼
[微信小程序]    选档 → 小程序虚拟支付组件 → 支付成功
      │  核销 → 写 entitlements
      ▼
[权益生效]      Web / iOS / Android 同账号可见   ← 🔴 当前不成立
```

**合规逻辑（2026-11-07 核实）**

- ICP **备案**（非经营性，已下证 `京ICP备2026075565号-2`）≠ ICP **经营许可证**（经营性增值电信业务，本项目 `[ ]` 未办，硬条件含 3 人社保）。Web 只要不直接收款/不下单，就不构成 Web 侧经营性信息服务收费。
- 微信小程序卖「解锁功能/订阅/会员」属**虚拟商品**：依据《虚拟支付业务运营指南》，购买与支付**均需接入小程序虚拟支付**，且**不得引导至 app、公众号、H5、个人号、网站完成支付**（该约束是「小程序内不得外跳支付」，Web 引导进入小程序属反向闭环，不冲突）。
- 2026-02-27 公告：**2026-04-01 起全终端（iOS / Android / 鸿蒙 / Windows）强制接入虚拟支付组件**；iOS 端已开放（需微信 8.0.68+、iOS 15+、Apple 支付配置小程序简称）。旧结论「iOS 小程序不能卖虚拟商品」已过时。
- 企业主体开通虚拟支付条件：**已认证小程序 + 企业/事业单位/个体工商户 + 主体信息完备**；开通时新开二级商户号（资料审核 1–7 工作日 + 账户验证 + 扫码签约），并在「道具管理」创建商品。行业口径下**自营虚拟商品只需备案 + 营业执照，不需要 ICP 经营许可证**（多商户平台才需 EDI；信息发布/内容社区类才常被要求 ICP 证）。
- 🔴 **小程序备案（工信部）是强制项**，当前用户告知「管局审核中」→ 既不能发布新版本，也不能完成虚拟支付开通。
