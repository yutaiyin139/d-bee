> - **依赖链**：`werun.mjs:86` 从入参 `auth` 解构 `const { exchangeWechatCode, authOwnerIdStrict } = auth`；`:109` 调 `await exchangeWechatCode({code,appid})`；`:117` 用 `exchanged.openid`、`:127` 用 `exchanged.sessionKey`。而 `auth` 就是 `app.mjs:65` 传入的 `createAuthHandlers()` 返回值。

> - 🟢 **「0 env / 不需升 `config.mjs`」仍然成立**：`auth.mjs` 的这 6 行只新增一个导出键、**不引入任何新 import、不读任何新 env**（其内部早已用生产已解析的 `wechatMiniSecrets`）→ 带上它的成本仅是「多传一个文件」，不带则是「埋一个只有用户能触发的 500」。

## 七、红线（照抄项目既有口径，不得弱化）

### 7.1 部署最高危

- 🔴🔴 **`deploy-gateway.sh` 是全站永久锁死级地雷**：缺 `IDENT_PEPPER` 即 `rand_hex` **重置** → **全站身份永久失效**（不可逆）；🔴 **只读 / 备份也绝不跑它**。网关变更**一律手术式脚本**，最新范式 = **`deploy/apply-llm-feature-walls.py`**（**13 道断言 + 自动回滚**；退出码 `0` 成功 / `1` 部署失败已回滚 / `2` 缺凭据 / `3` 预检失败未触碰生产 / `4` 部署后验证失败已回滚）。
  - 手术式铁律：前后断言 `gateway.env` **sha256 不变**；install 保持 `root:dbee 0644`；上传到 `$HOME` 暂存（**不经 `/tmp`**，避免 SFTP 0600 权限坑）。
- 🔴🔴 **绝不整搬本地 `app.mjs`**：本地 `app.mjs`（HEAD@`8bd68b5`）有 **3 个**生产不存在的顶层 import —— `:16` `'./xpay.mjs'`、`:17` `'./apppay.mjs'`、🆕 **`:20` `'./werun.mjs'`（WX-1 新加，雷区由 2 扩到 3，量化见 §4.3 C-3）** → node 在 **ESM 顶层解析阶段**抛 `ERR_MODULE_NOT_FOUND` = **网关启动失败 = 全站宕机**。只能「**生产现网副本 + 按唯一锚点插入**」。
  - 🔴 **同理 `auth.mjs`**：本地版 `:53` `import { saveSessionKey } from './wechatSession.mjs'` → **整搬 `auth.mjs` 而不先放 `wechatSession.mjs` = 同样全站宕机**。
- 🔴🔴 **重启前必做 ESM 预检**：须补齐**生产其余 `.mjs` + `package.json` + `node_modules` 软链 + `assets` 软链**（`iap.mjs` 顶层还读 `assets/AppleRootCA-G3.cer`、依赖 `node_modules/pg`），且🔴 **只 import `app.mjs`，不能 import `index.mjs`**（后者顶层 `loadConfig` 需 env，无 env 必抛）。
- 🔴🔴 **「状态谎报」比失败更危险**：bash heredoc 内**不得把 Python 常量名当 shell 变量**（`set -u` 崩在赋值行 → **回滚分支不执行、兜底文案却打印「已回滚」**）。危害：会让人以为生产是旧版而重复操作，或以为已回滚而放着真实新版不管。纪律：🔴 **报了回滚就必须真回滚过**，**回滚收敛到一个函数**，兜底文案不得与实际分支脱钩。
- 🔴 **`deploy/precheck-gateway-code.sh` 不够用**：只核对 4 个固定文件（`auth/identity/http/otp`），会漏掉 `lib/` 其余 11 个文件与 3 个缺失模块 → 🔴 **核对服务器代码漂移必须做 `lib/*.mjs` 全量 sha256 比对**，不能只比预置清单。
- 🔴 **nginx reload 有优雅退出窗口** → 立即验证会「**假红**」。修法 `sleep 8` + **重试 3 次**；🔴 **脚本必须可重入**。nginx 唯一生效模板 = `nginx.selfhost.conf.example`，改 nginx 只走 `deploy.sh APPLY_NGINX_CONF=1` 或 `switch-nginx-selfhost.sh`。

### 7.3 构建与产物

- 🔴 **原生包禁用 `npm run build`（白屏）**：内测 `npm run build:native:internal`；上架 `VITE_NATIVE_ENDPOINT=https://d-bee.cn npm run build:native`。
- 🔴 **`build:web` 会删 `dist/legal/`**（隐私政策静态页**零 JS 可爬** = **OPPO 硬要求**）；**native 与 web 共用 `dist/`** → 🔴 **部署 web 前必须重跑 `npm run build`** 并比对入口 js 文件名。**产物自检以 `index.html` 引用的入口 js 为唯一真源**（干净构建本就有 2 个 `index-*.js`）。
- 🔴 **改 `packages/shared/src` 后必重跑其构建**（`dist` 被 git-ignore，**护栏读 src 会假绿**）—— **项目已第三次踩**。
- 🔴 **Taro 输出目录与微信开发者工具工作目录同为 `mini/dist`，互相读写干扰**（实测关工具后 **69 → 20 文件**）→ **构建前必关工具**，🔴 **不得把工具当前显示的 dist 当产物真相**，验收只认构建刚结束那次。
- 🔴 **真机调试 ≠ 体验版**（调试会话注入 Web API，**掩盖 JSCore 缺口**）→ 小程序验收**一律以体验版为准**。
- 🔴 **护栏全绿 ≠ 可分发 / 可收款**（基线文件是**人工登记，非自动探测**）。
- 🔴 **`psql` / 脚本六铁律**：变更类**禁 `2>/dev/null`**（会吞掉报错 → 「应被拒」只看到没有结果行，**无法证明失败原因确实是 permission denied**，断言不成立）；探针**不打印真实 uid**（`set_config` 回显会打印身份面敏感值 → 用 `IS NOT NULL` 转布尔）；`SUDO()` **不吞 stderr**。
- 🔴 **写 SQL 前必核 `information_schema.columns` 列名**（例：`schema_migrations` → **`version` 非 `id`**；`ai_usage` → `usage_date` 非 `day`）。
- 🔴 **写库字段必须对齐生产库列**：`updateMealGrams` 曾写 `meal_entries.updated_at`（0030 漏列）→ `PGRST204 schema cache` → 前端误翻「服务版本不匹配」，**四端编辑份量全崩**（11-14 实证）。🔴 **用户报「服务版本不匹配」不是前端版本问题**，是 **schema cache / function 不存在**。加列后必 `NOTIFY pgrst, 'reload schema'`。

### 7.4 法务与合规

- 🔴 **法律公示公开信息真相源在 `packages/shared`，不得只放 `.env`**（被 gitignore → **换机器 / CI 静默产出无备案号页面**）。

### 7.5 云数据库安全

- 🔴 **发权益函数必须 `SECURITY DEFINER` + 入参白名单**；**涉权益表必须 `REVOKE authenticated` 的 `INSERT/UPDATE/DELETE`**（**RLS 挡不住直写**）。🔴 **0047 沿用此范式**。

### 7.6 工具坑（假绿 / 假阴性类，1–10 条）

| # | 坑 | 后果与修法 |
| --- | --- | --- |
| 1 | `unzip -o APK 'assets/public/*'` 的 `*` **不跨 `/`** | 子目录不被提取 → 「APK 内缺失 8 个文件」的**假象**。修法：**一律用 Python `zipfile`**（`Temp/apk-selfcheck.py` 已固化） |

| 10 | 🔴 **Taro 输出目录与开发者工具工作目录同为 `mini/dist`** | 互相读写干扰（实测关工具后 **69 → 20 文件**）→ **构建前必关工具**；🔴 **不得把工具当前显示的 dist 当产物真相**；验收只认构建刚结束那次。附带坑：**`/tmp` 对 Windows Python 不可见** → 跨工具传文件用 **`$TEMP`**；**跨仓库外目录一律用绝对路径**（在 `mini/` 下写 `../backup/...` 会指向不存在的路径 → 静默得到错误结论） |
