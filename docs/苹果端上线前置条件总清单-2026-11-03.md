```
软著登记（30–60 工作日，🔴 总闸门·未提交）
     ┐

               ↓
        ASC「App 信息」页填备案号 → 中国区提审
```

后两项**必须先在 Mac 上定下 DEVELOPMENT_TEAM 并完成签名**才能取到 → 备案材料才算齐。
（一个「证书+包名」组合只能备案一次，换证书或改包名须重办。）

## 四、🔴 需用户决策的悬置点：App 名称口径不一致

ASC 填备案号时会实时调 MIIT 接口强校验 **App 名称逐字一致**，不匹配返回 HTTP 409
`STATE_ERROR.ICP_NUMBER_MIIT_APP_NAME_MISMATCH`，**备案号存都存不进去**。当前两份文档口径冲突：

| 文档 | App 名称 |
| ---- | -------- |
| 《ASC配置-建App与配商品-操作清单-2026-10-25.md》§二 | `自律蜜蜂` |
| 《AppStore产品页-填报包-2026-10-28.md》§一 | `自律蜜蜂 - 饮食热量记录` |

**须用户拍板二选一并全链统一**（备案报名 / ASC 名称 / 软著登记名 三者必须逐字一致）：
- **方案 A**：统一用 `自律蜜蜂 - 饮食热量记录`（含副标题后缀，中国区展示信息量更足）→ 办 App 备案时按这一串逐字报名，同时改《ASC配置清单》§二。
- **方案 B**：统一用 `自律蜜蜂`（简洁，与软著名更易对齐）→ 改《填报包》§一名称字段。

> ⚠️ 软著登记名也须与最终 App 名一致（国内安卓商店强制校验），决策时一并考虑。

## 五、备案号下来后的连带回填动作（一次做完）

ICP 企业备案 + App 备案拿到备案号后：

1. 回填 `.env` 的 `VITE_ICP_BEIAN=<备案号>`（当前为空，产物里是 `""`，页脚不显示）
2. `npm run build` + `npx cap sync ios`（让 Web 页脚与 App「关于」页展示备案号，多地通管局要求 App 内标注）
3. 重新部署 web（按既有 web 流程，纯前端改动不动网关 env）
4. ASC「App 信息」页填备案号（触发 MIIT 校验，确认 App 名称/主体两项不报 409）
5. ASC **支持 URL / 隐私政策 URL** 从 IP 深链 `http://150.158.51.106/legal/*` 换成域名 `https://d-bee.cn/legal/*`（依赖 `d-bee.cn` 备案完成 + HTTPS 证书 + A 记录就绪）
6. 数据面决策：若切自建库，须先在自建库**重建演示账户 + 预置演示数据**（否则审核员登进空账户 → 2.1 拒审），并做云库→自建库用户数据迁移方案（`ident_hash` 需用自建库 `IDENT_PEPPER` 重算）

## 六、Mac 硬步骤（上架必经，Windows 无法代劳）

1. `npm install && npx cap sync ios`，Xcode 打开 `ios/App`
2. 编译 3 个本地 Swift 插件（`dbee-iap` / `dbee-health` / `origin-proxy`），修首次编译错误（10-23 静态审查已过，风险降为「低」）
3. **Signing & Capabilities：登录 Apple ID → 选 DEVELOPMENT_TEAM**（🔴 当前未设置 = 硬阻塞，无 Team 无法签名/Archive/Upload，连 TestFlight 都发不出）
4. 替换微信真实 AppID（如启用微信登录；当前占位 `wx0000…` 无副作用，入口本身隐藏）
5. ASC：创建 App（`cn.com.dbee.app`）→ 配 3 商品（`dbee_pro_monthly` ¥18 / `dbee_pro_yearly` ¥128 / `dbee_lifetime` ¥298）→ 接受付费协议（个人主体先按 W-8BEN + 本人卡）→ 生成 App 共享密钥
6. 服务器执行 `0037-apple-iap-settlement.sql` + 网关 env 配 `APPLE_BUNDLE_ID`/`APPLE_SHARED_SECRET` + 重启网关（🔴 **绝不跑 `deploy-gateway.sh`**，会覆盖 `gateway.env` 丢 `IDENT_PEPPER` → 全站永久锁死；用手术式脚本）
7. Archive → Upload → **TestFlight 内测**（沙盒账号走 `APPLE_SANDBOX=1`，验签已支持 21007/21008 自动切换）→ 待备案号齐 → **中国区提审**

> 🔴 **两个构建陷阱**：① 正式包须 `export VITE_NATIVE_ENDPOINT=https://d-bee.cn`（构建期护栏）；备案/HTTPS 未就绪前用 `VITE_ALLOW_CLOUD_NATIVE=true npm run native:sync:internal` 出**云库内测包（禁止上架）**。② **绝不能用 `npm run build` 打原生包**（Web 产物护栏被死代码消除成无条件 throw → iOS 白屏无报错）。自检：`grep -c "禁止直接复用 Web 产物" dist/assets/index-*.js` 必须为 `0`。
