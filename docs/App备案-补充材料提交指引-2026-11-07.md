## 〇、一句话结论

腾讯云里「补充材料」**有两个完全不同的上传位置**，别传错：

| 位置 | 在哪一步 | 传什么 | 本项目是否必传 |
|---|---|---|---|
| **A. 服务补充材料** | 步骤三「填写 APP 信息」→ 第 7 项，每个 APP 服务各自一份 | 前置审批类型（选项）、**APP 图标**、其他补充材料 | 图标**必传**；其余按需 |
| **B. 上传补充材料** | 步骤四「下一步，上传补充材料」→ 整单级弹窗 | 承诺书等盖公章的纸质件 | 看北京管局/控制台是否标必填 |

🔴 APP 服务的「服务补充材料」**只有三项**（前置审批类型 / APP 图标 / 其他补充材料）。
网站备案那套「域名证书 / 服务法定代表人授权书 / 域名实名认证截图」是**网站分支**的字段，APP 分支没有独立框；
若北京管局要这些材料，会由控制台动态加框，或走 A 的「其他补充材料」/ B 的弹窗上传。
**判据：控制台没出现上传框 = 不需要上传。**

> 本项目主体 `京ICP备2026075565号` 已在腾讯云备案，应走 **「新增/接入服务（原备案在腾讯云）」**，
> 不是「首次备案」；主体信息会自动带出，主要补的是 APP 侧材料。
> APP 备案与网站备案编号独立：网站 `京ICP备2026075565号-2`，APP 备案号形如 `…-2A`。

## 一、位置 A：服务补充材料（逐项怎么填）

### A1. 前置审批类型 → 选「以上都不涉及」

- 工信部 105 号文：仅**新闻、出版、教育、影视、宗教**等需提交主管部门审核同意文件；
  腾讯云另列药品和医疗器械、文化、广播电影电视节目、网络游戏等。
- 自律蜜蜂是「个人饮食与生活习惯记录工具」，项目既有结论（`docs/备案材料清单.md` §0）
  = **不需要前置审批**。
- 🔴 **服务内容（APP）必须选「生活服务 → 工具」或「生活服务 → 其他」**。
  《APP 备案服务内容目录》里有「医疗服务 → 健康护理」，**绝不能选**；
  选了就会被要求《医疗机构执业许可证》等前置材料，直接卡死。
- 备注/简介沿用 `docs/备案材料清单.md` §2 精简版（定位「个人记录 / 自我管理工具」、
  明写「不涉及医疗健康咨询」「不提供社交互动」「不涉及在线支付」），末尾补北京要求的应急电话说明。

**条件触发**：若控制台因营业执照经营范围关键词（如含「第二类增值电信业务」「健康咨询」「文化传播」等）
把「不涉及前置审批承诺书」标为必填，不要去办许可证，改交**《不涉及前置审批承诺书》**：

| 项 | 要求 |
|---|---|
| 模板 | 腾讯云《各省不涉及前置审批承诺书模板》(243/125088) 下载**北京版**，标题一般不用改 |
| 填写 | 承诺方 = 公司全称；逐项列明不涉及的前置审批项；APP 开办内容如实简述；**删光模板里所有红色提示文字** |
| 签署 | **加盖单位公章（红色鲜章）＋ 法定代表人亲笔手写签名**（不接受连笔签；部分省接受签名章） |
| 日期 | 手写，不晚于提交日，且在管局审核前 3 个月有效期内 |
| 上传 | 打印 → 填写 → 签字盖章 → 彩色拍照/扫描，传到控制台标「不涉及前置审批承诺书」的那个框 |

### A2. APP 图标 → 必传，现成文件可直接用

- 项目已有 `public/icon-512.png`（512×512 PNG），与 App 安装后图标一致即可。
- 备案表单侧格式：`png / jpeg / jpg`，**单文件 ≤ 2 MB，最多 1 张**（公安平台口径，腾讯云备案侧同规格）。
- 图标必须是**对外实际使用的那个**，不要临时做个「备案专用图」。
- 名称口径：APP 名称填安装后图标下方显示的名称 → **`自律蜜蜂`**（11-07 定案），
  与软著名、各商店上架名逐字一致。

### A3. 其他补充材料 → 没有就留空

官方原文：「如有 APP 其他补充材料可点击上传，**没有则不需要上传**」。
本项目可能被要求放的，按出现概率排序：

| # | 材料 | 什么时候要 | 从哪来 |
|---|---|---|---|
| 1 | **域名实名认证截图** | 非腾讯云注册域名常被要求 | 阿里云万网后台；截图须含域名、所有者、证件类型、证件号、过期时间 |
| 2 | **域名证书** | 控制台出现「域名证书」框时 | `d-bee.cn` 权威 DNS `dns25.hichina.com` = **阿里云万网，非腾讯云** → 去阿里云下载，不是腾讯云 |
| 3 | 法人非京籍的**北京居住证 / 连续 6 个月北京社保** | 北京管局 2026 规则；项目文档列为「待确认法人户籍」 | 用户本人提供 |
| 4 | 《服务法定代表人授权书》 | 服务负责人不是法定代表人时（本项目主体负责人=法人，大概率不用） | 腾讯云 243/14968 模板 |
| 5 | 《不涉及前置审批承诺书》 | 见 A1 条件触发 | 243/125088 北京版 |

> 🔴 域名实名信息必须与备案主体「北京迪蜂科技有限公司」**完全一致**，
> 且域名有效期 > 1 个月；APP 备案的域名填 `d-bee.cn`（不是公司官网 `d-bee.com.cn`）。
> 需要填写的云资源 = 那台腾讯云轻量应用服务器（`150.158.51.106`）或备案授权码。

## 二、位置 B：步骤四「上传补充材料」（整单级弹窗）

点「下一步，上传补充材料」后弹出，**上传本次备案所需的其他备案材料，例如承诺书等**。
模板统一在腾讯云《备案材料模板下载》(243/14968) 取。企业主体常见件：

| 材料 | 签署要求 |
|---|---|
| 《互联网信息服务备案承诺书》/《单位备案承诺书》 | 单位**加盖公章** + 手写日期；把模板里「住所所在地」改成「北京市」再打印 |
| 《真实性核验单》（如控制台要求） | 法人签字 + 公章 |
| 营业执照副本（复印件时） | 加盖公章 |
| 法人身份证正反面 | 原件拍照；复印件需盖章，水印只能写「仅用于备案」 |

盖章质量红线（沿用 `docs/公章使用清单-2026-10-27.md` §0.3 / §五）：
公章红色鲜章、清晰不压字、不用财务章/合同章/电子签章、公司名逐字一致、
原件彩色拍照或扫描（**不隔屏翻拍、不黑白复印**）、JPG/PNG/PDF、单张 ≤ 5 MB。
项目 4 枚章已齐（公章/财务章/发票章/法人名章），无补刻需求。

> ⚠️ **软著、算法备案、公安联网备案不是 App 备案的补充材料**：
> 软著是安卓商店上架资质、算法备案走网信办、公安备案是 ICP 通过后 30 日内另办
> （且 **APP 备案不支持生成公安联网备案数据码**，须自行去 beian.mps.gov.cn 填）。
> 不要把它们塞进这个弹窗。

## 三、同一订单里「不是补充材料但同一步要交」的

- **服务负责人信息（APP）**：证件照人像面/国徽面 + **微信扫码视频人脸核身**；
  企业备案可代办（法人或经办人任一人核身即可）；同订单多个服务只需核身一次。
- **APP 特征信息**：域名、运行平台、包名 / 公钥 / 签名 MD5。
  安卓真值已复核（四源逐字一致）：`cn.com.dbee.app` / 公钥模数见
  `release/App备案-三平台签名信息-20261107.md` / MD5 `0abe7fc5005987ed9b6eae9a45fb9dc9`。
  iOS / 鸿蒙缺证书 → **待拍板**：一次报三平台，还是先报安卓、拿号后再走「变更备案」补平台。
  （腾讯云：同款 APP 不同运行平台用同一名称只需备案一次；新增运行平台走变更类型业务。）
- **使用外部 SDK**：选填。微信/支付宝支付、扫码等能选到厂商就如实登记；
  找不到对应厂商的功能类型就别选、直接选「不使用外部 SDK」。

## 四、提交之后怎么补件 / 怎么算完成

1. **腾讯云初审** 1–2 工作日，会**电话**联系确认订单；两次打不通直接驳回 → 手机号务必可接通。
2. **工信部短信核验**：提交后 24 小时内到 beian.miit.gov.cn 完成，**超时订单自动作废、材料全白填**；
   核验后进入管局审核即无法撤回（发现填错就故意不核验、等失效重交）。
3. **管局终审** ≤ 20 工作日（北京）。
4. **被驳回补件**：`我的备案` → 被驳回订单 → **去修改并重新提交** →
   按驳回原因把签字盖章件的扫描件传到对应框（例如「不涉及前置审批承诺书」处），再提交。
   前置审批文件要删改：`我的备案` → 变更 → 「我要变更服务信息」→ 服务补充材料 → 前置审批类型 → 改回「以上都不涉及」即可删除。
5. **拿号后必须做**：APP 备案号形如 `京ICP备2026075565号-2A`（**不是网站号 `-2`**），
   要在 App「设置 / 关于我们」显著位置标注，并在编号下方链接 `https://beian.miit.gov.cn/`。
   🔴 项目 `packages/shared/src/constants/index.ts` 目前**只有** `ICP_BEIAN_D_BEE_CN = '京ICP备2026075565号-2'`（网站号），
   `POLICE_BEIAN = ''`（公安号待回填）。App 备案号下来后需新增常量并在四端展示 —— 属代码改动，待批准，未擅自改。
