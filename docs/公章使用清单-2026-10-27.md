### 0.2 🔴 短信签名「自律蜜蜂」现在申请不下来 —— 这是个真坑

原计划：签名「自律蜜蜂」。**按腾讯云最新《签名审核标准》（2026-04-20 更新）逐条核对，5 种签名类型当前全部不满足**：

| 签名类型    | 要求                           | D-Bee 现状              | 结论              |
| ------- | ---------------------------- | --------------------- | --------------- |
| **公司**  | 营业执照全称/简称 + 资质报备通过           | 营业执照 ✅、公章 ✅           | ✅ **唯一现在就能办的**  |

| 网站      | **工信部网站备案截图** + 备案主体=营业执照    | 备案仍是**个人**主体（企业重备未开始） | ❌（等企业重新备案通过后可用） |
| 公众号/小程序 | **小程序后台归属证明截图** + 小程序主体=营业执照 | 小程序仍是**个人**主体         | ❌（等主体变更后可用）     |
| 商标      | 商标注册书                        | 无注册商标                 | ❌               |

> 另外：**2025-09-18 起腾讯云不再支持「个人自用签名」**，个人认证用户只能申请「他用签名」→ 必须走企业资质。这也是当初「等公章」的根本原因。

**三条路径，建议「A 先跑 + C 后补」双签名并行**：

| 路径          | 签名内容              | 何时可办                   | 代价                                                  |
| ----------- | ----------------- | ---------------------- | --------------------------------------------------- |
| **A（推荐先做）** | 公司**简称**（如「XX科技」） | **今天**，资质报备通过即可        | 需改网关 `SMS_SIGN_NAME`；短信变成【XX科技】您的验证码是…              |
| B           | 自律蜜蜂（小程序类型）       | 小程序主体变更完成后（约 1–2 周）    | 需小程序名称确为「自律蜜蜂」+ 后台基本设置页截图                           |
| **C（推荐后补）** | **自律蜜蜂**（网站类型）    | ICP 企业重新备案通过后（约 2–4 周） | ✅ 网站名称本就是「自律蜜蜂」（见《备案材料清单.md》§1.2）→ **签名不变，网关代码零改动** |

> 腾讯云一个账号可持有多个签名，`SendSms` 用 `sign` 参数指定。**所以：今天先报「公司」类签名让短信能发（万能码尽快下线），备案下来后再补报「自律蜜蜂」，然后把 `SMS_SIGN_NAME` 切回去。**

⚠️ **签名内容硬限制**：2–12 个汉字（不含【】），建议 ≥4 字、尽量中文；简称必须**连续全部包含在营业执照全称中**，且官方建议带地域属性（例：「深圳市XX科技有限公司」→ 简称取「深圳XX科技」，不要只取「XX科技」）。若公司全称本身 ≤12 字可直接用全称。

### 0.3 🔴 盖章件的头号驳回原因：章不合规

微信开放平台/华为/管局审核员的高频驳回点，逐条对照：

- ❌ 用**财务章、合同章、电子签章**代替公章 → 直接判「非法定公章」，法律背书失效
- ❌ 公章**模糊、晕染、盖到文字上遮挡内容** → 退回重交
- ❌ **黑白复印件上的章是黑的** → 所有证明文件必须是**原件图片，章为红色**
- ❌ 公司名称**漏字**（漏「有限公司」「科技」）→ 判「主体不一致」
- ✅ 正确做法：**彩色扫描 / 手机拍照原件**，章清晰、红色、不压关键文字，JPG/PNG，单张 ≤5 MB

> **实操建议**：今天一次性把要盖章的材料全部打印出来，集中盖完再统一扫描/拍照，比一项一项来回找章省 3 倍时间。
