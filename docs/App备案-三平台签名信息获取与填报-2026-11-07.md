## 三、iOS 平台 🔴 待补证书（获取路径已备齐）

**当前状态**：仓库内**没有** Apple Distribution 证书（仅有 `server/assets/AppleRootCA-G3.cer`，是 Apple 根 CA，不是应用签名证书）；
`ios/App/App.xcodeproj` 的 `DEVELOPMENT_TEAM` 未设置 → 尚未生成正式的 iOS Distribution 证书。

**需要拿到的文件**：Apple Developer → Certificates, Identifiers & Profiles → Certificates → 下载 **iOS Distribution (App Store and Ad Hoc)** 证书（`.cer`）。

**步骤**：
1. 登录 https://developer.apple.com/account/resources/certificates/list （需 Apple 开发者账号；Mac 上生成 CSR）
2. 下载对应证书，放到 `signing/ios-distribution.cer`（该目录已被 `.gitignore` 排除）
3. 跑：
   ```bash
   python tools/app-beian-signing.py cert signing/ios-distribution.cer --platform ios
   ```
4. 从输出抄：**公钥（模数）** + **SHA-1**（填到「签名MD5值」栏）
5. Bundle ID 填 `cn.com.dbee.app`（在 Certificates 页 Identifiers 里核对）

> 🔴 备案用**证书**信息，不是 `.mobileprovision`、也不是 IPA 内嵌描述文件。
> 🔴 iOS 与安卓共用同一 `applicationId` 是允许的，但备案按平台分别填特征信息。

## 四、鸿蒙平台 🔴 待补工程与证书（获取路径已备齐）

**当前状态**：仓库内**没有鸿蒙工程**（无 `harmony/` / `ohos/`），AGC 应用未登记 → 包名待定。
备案要求「一个证书 + 包名组合只能备案一次」，所以要先在 AGC 定包名再取证书。

**步骤**：
1. 登录 https://developer.huawei.com/consumer/cn/service/josp/agc/index.html → 开发与服务 → 选/建应用 → 记下**包名**
2. 「证书、APP ID 和 Profile」→「证书」→ 下载**鸿蒙应用开发者证书**
3. 华为云指引要求**删除证书链部分、只保留叶子证书**；本工具会自动完成，也可手动用文本编辑器删
4. 放到 `signing/harmony-developer.cer`（或 `.pem` / `.p7b`），跑：
   ```bash
   python tools/app-beian-signing.py cert signing/harmony-developer.cer --platform harmony
   ```
5. 从输出抄：**公钥** + **SHA-1 指纹**（填到「签名MD5值」栏）

> 工具会自动识别 PEM/DER/PKCS#7、自动剔除根证书与中间证书，并在输出里写明取了哪一张，便于人工复核。

## 五、工具用法速查

```bash
# ① Android 真值（默认扫 release/ 下最新的 *FORMAL* 包；凭据不回显）
python tools/app-beian-signing.py android
python tools/app-beian-signing.py android --apk release/<新包>.apk

# ② iOS / 鸿蒙证书
python tools/app-beian-signing.py cert signing/ios-distribution.cer --platform ios
python tools/app-beian-signing.py cert signing/harmony-developer.cer --platform harmony

# ③ 一键汇总三平台为可照抄的填报表（证书到位后自动纳入）
python tools/app-beian-signing.py report --out docs/App备案-签名信息速查-自动生成.md
```

工具依赖：`cryptography>=42`（本机 50.0.1）、JDK `keytool`（本机 21）、Android SDK `apksigner.jar`（本机 build-tools 37.0.0）。
**凭据纪律**：`keystore.properties` 的密码只在进程内读入并经环境变量传给 keytool，
不打印、不进命令行参数、不落盘；`android/keys/` 与 `keystore.properties` 已被 `.gitignore` 排除。

## 六、与今天 Android 打包的关系

本轮 `versionCode` 14→15 后重打 Release 包，仍用同一 keystore 签名，因此：
