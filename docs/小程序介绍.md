# D-Bee 小程序介绍

## 一、产品定位

**D-Bee（自律蜜蜂）** 是一款以「AI 拍照识别 + 健康自律打卡」为核心的轻量健康管理小程序。它把每天最琐碎、最容易放弃的健康记录动作，压缩成「拍一张照片」「点一下打卡」，用积分和会员机制让坚持变得有正反馈。

一句定位：**拍张照，记住今天吃了什么；打个卡，让自律看得见。**

---

## 二、核心功能

### 1. AI 拍照识别饮食（核心亮点）
- 拍一张食物照片，AI 自动识别食材、估算热量与营养，免去手动逐条录入。
- 支持**文字描述识别**（口述「一碗牛肉面」也能解析）、**条码扫描**。
- 每日提供 **3 次免费 AI 拍照识别**，另可用积分兑换 **2 次**。

### 2. 健康打卡（零门槛）
- **运动**：记录步数、运动类型与时长，接入手机健康数据自动同步。
- **饮食**：手动录入或拍照识别，生成每日饮食报告。
- **饮水**：一键记录饮水量，追踪饮水目标。
- **体重**：记录体重趋势曲线。

### 3. 积分体系（蜜糖 Honey）
- 连续打卡、完善资料、邀请好友均可获得**蜜糖积分**。
- 积分可兑换：AI 拍照次数（50 分/次）、Pro 会员（100 分/天、2600 分/30 天）。

### 4. 会员（Pro / 买断）
- **Pro 月付 ¥18 / 年付 ¥128**：AI 拍照识别无限次、饮食报告回看 30 天。
- **终身买断 ¥298**：一次性解锁全部权益。
- 免费用户饮食报告可回看 7 天。

### 5. 多端同步
- 微信 / 支付宝 / 抖音三端小程序 + Web + iOS / Android App，**同一账号数据全端同步**。

| 亮点 | 说明 |
|---|---|

| 轻量克制 | 不做大而全，专注「记录 + 坚持」这一件事 |

## 四、目标用户

- 想控制饮食、管理体重的**减脂/健身人群**
- 希望养成规律作息、运动、饮水习惯的**自律爱好者**
- 喜欢用 AI 工具降低记录成本、追求效率的**轻健康用户**

---

## 五、技术架构（简要）

- **多端一套代码**：基于 Taro 4（React）+ 统一「共享规则包」，四端共享同一份额度/定价/会员逻辑，避免规则不一致。
- **云端一体**：登录、数据、AI 识别、积分、会员统一走云端服务，多端数据天然打通。
- **平台登录**：微信一键登录；支付宝 / 抖音 / 手机号验证码登录。
