## 〇、结论先行（决策者只读这 7 条）

1. **「政策不允许收费」这件事基本不成立。** 四端在现行中国法规下**都能合法收费**；真正存在的是：① 一个**全端总闸门**《增值电信业务经营许可证（B25，下称 ICP 经营许可证）》；② 两项**渠道强制**（小程序必须虚拟支付、iOS 必须 IAP）；③ 四项**备案在审的状态阻断**（待批，不是禁止）。
2. 🔴 **最紧急、最长杆、且此前被错误搁置的是 ICP 经营许可证。** 11-06「暂不办」的旧决策作出时项目「不引入在线支付」，**前提已被本次指令推翻**。国务院令 292 号第 3/4/7/**11** 条明确「**非经营性互联网信息服务提供者不得从事有偿服务**」，第 19 条规定罚则。办证周期（含材料准备）实务 60–90 工作日 → **应当立即启动，而不是等收费上线再补**。
3. **Android 完全可以收费，且是政策最宽松的一端**；卡点不是政策，是「**工程链路全缺失 + 商户号未签约 + 备案/软著未下**」。阶段 0 按 (B)「明确不收款」执行是**错误决策，予以撤销**，改判 (A) 实装。
4. **mini 是唯一不依赖 ICP 经营许可证、不依赖软著、且代码 100% 就绪的端** → 仍是**第一笔收入的最短路径**。🔴 且政策刚放宽：**微信 2026-02-11 起全面支持 iOS 端小程序虚拟支付**（15% 优惠费率），适用 Android/iOS/鸿蒙/Windows 全终端 —— 项目里「iOS 小程序不能卖虚拟商品」的旧认知已过期。
5. **Web 不是「永久不收款」，是「办证后可收款」**。但受《微信小程序平台运营规范》2.5.13 / **2.14.7** 约束，**Web 不得成为「小程序虚拟商品」的支付落地页**（明确禁止引导至网站、安卓支付完成支付）→ Web 若收款，必须是**独立权益、独立通道、独立资质**，与 mini 完全隔离。
6. **绝对不可提前的只有三件事**：开 `D_BEE_XPAY_ENABLED`（6 项前置未就绪）、上生产 `0046` / 部署 `xpay.mjs`+`iap.mjs` / 补支付 env（🔴🔴 **绝不跑 `deploy-gateway.sh`**，缺 `IDENT_PEPPER` 会全站身份永久失效）、停云库实例（不可逆）。
7. **现在最该做的是「启动长周期资质 + 并行补 Android/Web 共性支付服务端」**，两者都零生产风险且能显著缩短关键路径。详见 §六。

### 3.6 【D】不得「展示价格却无法成交」——为什么现在不能提前开按钮

| 项 | 内容 |
| --- | --- |
| 法源 | **《广告法》第 4 条**（广告不得含有虚假或者引人误解的内容，不得欺骗、误导消费者）；**《网络交易监督管理办法》第 14 条**（禁止虚假或引人误解的商业宣传）、**第 19 条**（全面真实准确及时披露）、**第 21 条**（格式条款）；《消费者权益保护法》第 20 条 |
| 平台侧 | 微信小程序运营规范 **2.14.1/2.14.2**（支付行为须在简介明确指示、支付前页面明确提示）、**2.2.3**（名称/简介禁商业化用语）、2.6.3/2.6.4（禁虚假夸大、煽动误导） |
| **对本项目的判断** | 阶段 0 的 `THIRD_PARTY_CHECKOUT_ENABLED=false` 与 Web「零下单字样」**在底层未实装时是合规必需，不是产品克制**。代码实证：把门控改 true，Android 会渲染支付按钮，但 `fetchPrepayParams` 恒 `null`（`wechatPay.ts:176-179` / `alipay.ts:149-152`）→ 抛「正在接入中」；服务端无预下单端点、`verify_payment_order` 对 wechat/alipay 恒 false（`0021:151-158`、`0046:460-466`）→ **点了必然失败、无资金无权益**。这种「可点但收不到钱」正是被规制的情形。**结论：门控与实装必须同批上线。** |

## 五、关键路径与依赖链（谁卡谁）

```
【全端总闸门 · 最长杆，立即启动】

软著 / APP 电子版权（30–60 工作日，可加急）────┼──→ Android 商店上架 ──┐
App 备案（🔄 审核中）───────────────────────────┘                      │
                                                                        ├──→ 微信 APP 支付权限 ──→ Android 收款
微信开放平台资质认证 + 移动应用 AppID（7 工作日，官网已就绪）──────────┤        （A7~A13 实装完成后才能开按钮）
微信支付新商户号入驻（APP 场景，下载链接选填，7 工作日）──────────────┘

【mini 首发 · 不依赖 ICP 证 / 不依赖软著 / 代码已 100% 就绪】
小程序备案（🔄）→ 微信认证 → 虚拟支付签约(1–7d) → 三档道具发布 + 消息推送开启
   → 0046 上生产 → 网关部署 xpay.mjs → 5 个 env 手术式补齐 → 开 D_BEE_XPAY_ENABLED
   → 体验版全链路验收 → ✅ 第一笔收入

【iOS】
App 备案 + 软著 + Mac/Xcode26 重打包 → ASC 3 商品 + 付费协议/税务/银行
   → iap.mjs 部署 + APPLE_* env → 5 日提醒机制 → 沙盒/TestFlight → 中国区提审 → ✅
```
