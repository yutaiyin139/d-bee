## 二、今天（10-28）执行顺序

### 🔴 P0-1 · ASC 付费协议 + 银行 + 税务（iOS IAP 总开关，约 40 分钟）

**为什么排第一**：协议状态不到「有效」，**连沙盒购买都拉不起来**，后续 1.9/1.10 全部空转。
Apple 走电子签署 + 银行信息，**一般不需要中国公章**，是对公账户解锁项里唯一零依赖的。

路径：App Store Connect → 商务 → 协议、税务和银行业务（🔴 只有「账户持有人」职能本人能签协议，管理员/财务只能查看）

1. 接受**付费应用协议**（Paid Applications Agreement，电子签署，无需中国公章）
2. 填**银行账户**（见下方 ⚠️ 主体一致性风险）
3. 填**税务信息**：⚠️ **10-28 修正——当前 Apple 账号是「个人主体」，系统只给 W-8BEN（个人表），填不了 W-8BEN-E（企业表）**。W-8BEN-E 要等 1.12 账号迁移为组织主体后才会出现。
4. 填**联系人**（法务/财务/高级管理三类联系人，可同一人）

> 🔴 **10-28 核实的关键风险（原文档漏了）**：Apple 官方《输入银行业务信息》明确「在『账号』栏中，输入 **Apple Developer Program 注册者（个人或法律实体）** 的银行账号」——
> 即**个人主体账号原则上要绑本人账户，公司对公账户不是注册者的账户，有被拒/后续付款异常风险**。
> 而《AppStore发布-完整准备清单.md》§3.2 也早已写明「**收款主体须与开发者账号主体一致**」。
>
> **因此「今天可办」要收窄口径**：今天能办的其实是**个人主体版本**（W-8BEN + 本人储蓄卡，拼音户名与 Apple 存档一字不差）。
> 沙盒测试与 TestFlight 只需要「协议状态 = Active」，**不校验收款账户是谁** → 个人版本足以解锁 1.4/1.6/1.10 全链。
> **但生产售卖前必须完成账号迁移（1.12，等 D-U-N-S）→ 重签付费协议 + 重填 W-8BEN-E + 换绑对公账户**，
> 迁移期间「Certificates, Identifiers & Profiles」会暂不可用，且迁移开始时的银行账户会收到迁移前收入 → 换绑要在迁移前想清楚。
> 好消息：1.13 提审本来就要等 App 备案号（2–5 周后），迁移有充裕时间窗，**不抢今天的关键路径**。

验收：协议状态显示「**有效**」（Active）。⚠️ 提交后可能需数小时至 1–2 天才转「有效」，
提交完立即推进下一步，不要干等。📌 **税务表提交后在 ASC 内不可自行修改**，填错只能联系 Apple。

### 🔴 P0-2 · ASC 建 App + 配 3 商品（约 30 分钟）

   **`cn.com.dbee.app` 已定案且已固化在 5 处代码，不要改**（改 = 老安装变新 App + ASC 记录重建）。

### 🟡 P1-1 · 网关配 APPLE_* 三项（我来做，约 15 分钟）

拿到 P0-3 的共享密钥后，一条命令部署（代码已在服务器上，只补 env）：

```bash
DBEE_HOST=150.158.51.106 DBEE_USER=ubuntu DBEE_PWD='<SSH密码>' DBEE_APP_PWD='<dbee_app密码>' \
APPLE_BUNDLE_ID='cn.com.dbee.app' \
APPLE_SHARED_SECRET='<P0-3 拿到的共享密钥>' \
APPLE_ALLOWED_ENVS='Sandbox,Production' \
CORS_ALLOWED_ORIGINS='http://150.158.51.106,capacitor://localhost,https://localhost' \
    bash deploy/deploy-gateway.sh
```

🔴 **`APPLE_ALLOWED_ENVS='Sandbox,Production'` 必须显式带**：一旦同时设了 `DBEE_PROD=1`（短信切换会设），
`appleAllowedEnvs` 默认值会收紧成**只收 Production** → iOS 未提审、沙盒购买验签**全部失败**。
上架后再去掉这个变量即自动收紧（这正是安全审计④的设计意图）。

验收：`curl` 打 `/.cloud/payment/apple/verify` **不带 Bearer 返回 401**（而非 503）；
`journalctl -u dbee-gateway` 无 `iap_not_configured`。

⚠️ 已知部署坑（10-27 踩过）：`deploy-gateway.sh` 渲染 env 时若 `.secrets.local` 缺 LLM 密钥，
会把 `LLM_API_KEY`/`LLM_VISION_API_KEY` 写成空值 → 线上 LLM 503。**部署后必须查启动日志无「LLM_API_KEY 未配置」告警**。
