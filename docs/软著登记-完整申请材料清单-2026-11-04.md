### 9. 开发目的

为个人用户提供一款**便捷、AI 驱动的饮食与生活习惯记录工具**：通过拍照与条码扫描快速记录每日饮食，自动估算热量与营养素，帮助用户建立饮食自我认知、养成自律习惯，实现「让每一口都吃得明白」。填补传统手动记录繁琐、缺乏营养素深度的痛点，同时坚持统一定价、免费版永久可用，降低使用门槛。

### 10. 面向领域 / 行业

**移动互联网 · 健康生活 / 个人健康管理工具（饮食记录细分领域）**

> 合规红线：定位为「饮食记录 / 健康生活工具」，**不得**表述为「医疗诊断 / 治疗 / 减肥疗效」；所有数据均为参考估算值。

### 11. 软件的主要功能

1. **AI 拍照识别**：拍摄餐盘照片，自动识别菜品、估算分量与热量，并给出三大营养素分析；识别成功才扣次数。
2. **包装条码扫描**：扫描商品条码，秒出营养标签（钠、膳食纤维、添加糖等微营养素），永久免费不限次。
3. **饮水 / 体重 / 运动打卡**：按体重自动计算饮水目标，运动消耗实时融入每日能量缺口。
4. **内置食物库**：1200+ 常见食物，覆盖家常菜、生鲜与加工食品，含微营养素数据。
5. **AI 问答复盘**：针对用户个人记录数据答疑复盘（免费版限流、Pro 不限流）。
6. **饮食报告与数据导出**：热量 / 营养素趋势图表，Pro 扩展更长期限与数据导出。
7. **连续打卡与成就徽章**：12 枚成就徽章，打卡里程碑解锁。
8. **会员订阅体系**：免费 / Pro 月订阅 / Pro 年订阅 / 终身买断四档，统一定价、可随时取消。

### 12. 软件的技术特点

1. **跨端一体化架构**：单一 React 前端经 Capacitor 封装为 Web / iOS / Android 三端，另以 Taro 构建小程序端，`packages/shared` 收敛三档权益规则与常量，实现「一套业务逻辑、多端复用」。
2. **AI 视觉识别 + 大模型问答**：拍照识别菜品与营养，结合用户记录数据提供个性化复盘问答。
3. **双层安全护栏**：构建期（Vite 插件）与运行时（resolveEndpoint）双重校验，防止端点钉死或错误分发，保障四端数据面一致性。
4. **多租户数据隔离**：PostgreSQL RLS 行级安全策略 + SECURITY DEFINER 函数，实现用户数据强制隔离。
5. **AI 识别失败不扣费**：识别成功才扣次数，保障用户权益的公平计费策略。
6. **数值口径统一**：`numfmt.ts` 全站唯一舍入/格式化实现，杜绝「先舍入再计算」的精度误差（供能比配平等）。

## 七、执行步骤

1. 定死**软件全称 + 版本号**（§五）→ 三处同步（软著 / App 备案 / 各商店）。
2. 你亲自撰写**软件说明书**（15–30 页，图文并茂，含开源组件授权标注）。
3. 生成**源程序鉴别材料**（60 页 × ≥50 行，页眉 = 全称 + 版本号）。
4. 在线填报申请表 → 打印签章页 → **盖公章 + 亲笔手抄诚信说明 + 签名 + 身份证号** → 扫描 PDF。
5. 营业执照副本复印件盖公章。
6. 提交（www.ccopyright.com.cn 全流程网办）。
7. 🔴 **补正通知只在官网消息中心（站内信）发送**，30 日内不补正视为撤回 → 提交后每周登录查站内信。
8. 拿证后：填 App 备案 → 各安卓商店上架 → iOS 中国区提审（需 App 备案号）。

> 页眉一致性铁律：申请表、源程序页眉、说明书页眉三处「软件全称 + 版本号」必须逐字一致，这是最高频补正原因。
