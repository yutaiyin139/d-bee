### 🟢 P1 · 短信协议签署 + 通道切换（5.6）—— **审核已通过，2026-10-27**

✅ **短信审核已通过、短信可用**（2026-10-27 用户确认）。切换从「改服务器 env 文件」简化为**一条命令**（部署脚本已接线，见下方 §切换命令）。

1. ~~腾讯云控制台签短信服务协议、充值短信包~~ ✅ 已完成。
2. 建**短信子账号** API 密钥（CAM 最小权限，别用主账号密钥）→ 得 `SecretId` / `SecretKey`。
3. 创建应用拿 `SdkAppId`；签名与**模板**「您的验证码是{1}，{2}分钟内有效」已审核通过 → 得 `TemplateId`。
   ⚠️ 模板参数按位对应：`{1}`=验证码、`{2}`=有效分钟（`sms.mjs` 的 `TemplateParamSet` 传 `[code, otpTtlMin]`）。
4. **切换命令**（本机执行；四项凭据会持久化到 `deploy/gateway/.secrets.local`，下次部署不必重传）：
   ```bash
   DBEE_HOST=150.158.51.106 DBEE_USER=ubuntu DBEE_PWD='<SSH密码>' DBEE_APP_PWD='<dbee_app密码>' \
   SMS_PROVIDER=tencent DBEE_PROD=1 \
   SMS_TENCENT_SECRET_ID='<SecretId>' SMS_TENCENT_SECRET_KEY='<SecretKey>' \
   SMS_TENCENT_SDKAPPID='1400xxxxxx' SMS_TENCENT_TEMPLATE_ID='<模板ID>' \
   CORS_ALLOWED_ORIGINS='http://150.158.51.106,capacitor://localhost,https://localhost' \
   APPLE_ALLOWED_ENVS='Sandbox,Production' \
       bash deploy/deploy-gateway.sh
   ```
   脚本自动完成：注入四项凭据 → **摘除 `SMS_MASTER_CODE`**（万能码后门关闭）→ 追加 `DBEE_PROD=1` →
   部署代码 + `pg_dump` 备份 + `systemctl restart` + healthz 探活。
   🔴 **两个连带效应（必须知情，脚本也会提示）**：
   - `DBEE_PROD=1` → **Apple 收据默认只收 Production**，iOS 沙盒购买会验签失败 →
     提审期务必带 `APPLE_ALLOWED_ENVS=Sandbox,Production`（上架后去掉即自动收紧）。
   - `DBEE_PROD=1` → **CORS 未配白名单则拒绝所有跨域请求**（同源不受影响）。当前 Web 走 nginx 同源反代，
     配不配都能跑；为保险起见按上面带上（HTTPS 就绪后把 `http://150.158.51.106` 换成 `https://d-bee.com.cn`）。
5. **验收**：新手机号注册收真短信；`journalctl -u dbee-gateway | grep SMS` 只见掩码号 + `SerialNo`，**无明文验证码**；
   旧万能码登录必须失败（`config.validate` 已拦「tencent+万能码」，网关起不来即说明没摘干净）。
   ⚠️ 常见失败码：`FailedOperation.InsufficientBalanceInSmsPackage`（短信包余量不足）、
   `LimitExceeded.PhoneNumberDailyLimit`（同号日限）、`FailedOperation.PhoneNumberInBlacklist`。
