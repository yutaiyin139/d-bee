## D-Bee 原生 App 化 · 阶段 0：代码解耦（完成）

按 `docs/原生App化方案.md` §4 阶段 0 执行纯重构，**Web 端行为零变化**。

### 新增 5 个抽象模块（`src/lib/`）

| 文件 | 职责 | Web 实现 | 原生目标实现 |
|---|---|---|---|
| `platform.ts` | `isNative()/isIOS()/isAndroid()/isWeb()/isWebView()` | 探测 `window.Capacitor`，一律 false | 同（真值） |
| `kv.ts` | KV 存储 `kvGet/kvSet/kvRemove` + JSON 便捷方法 | `localStorage`（不可用时退内存 Map） | `@capacitor/preferences` |
| `capture.ts` | `takePhoto()` / `pickFileFromInput()` / `PHOTO_INPUT_PROPS` | `<input type=file capture>` | `@capacitor/camera` |
| `scan.ts` | 扫码门面，转发到 `barcode.ts` | 原 `getUserMedia`+zxing/BarcodeDetector | `@capacitor-mlkit/barcode-scanning` |
| `share.ts` | `exportFile()/exportJSON()/exportText()` | `createObjectURL`+`a.download` | `@capacitor/filesystem`+`@capacitor/share` |

关键设计：所有模块用**运行时鸭子类型探测** `window.Capacitor`，不 import 任何 Capacitor 包，
因此 Web 构建产物零新增依赖、包体积不变（已用 `vite build` 确认）。

### 改造的既有文件

- `src/cloudConfig.ts` — `resolveEndpoint()` 重构为**三层优先级**：①`VITE_CLOUD_ENDPOINT` 显式覆盖
  ②**原生分支**（新增，`VITE_NATIVE_ENDPOINT` → 否则 `CLOUD_HOST`；用 `isUsableEndpoint()` 拒绝
  `capacitor://localhost` 等本地来源）③Web 运行时 origin（Nginx 同源反代）→ 兜底 `CLOUD_HOST`。
  新增 `trimSlash()` / `detectNative()` / `isUsableEndpoint()` 三个辅助函数。
  `detectNative()` 刻意不 import `lib/platform`，避免 cloudConfig 这个最早求值的模块产生循环引用。
- `src/main.tsx` — SW 注册显式加 `isNative()` 判断；原生端额外**反注册**历史 SW
  （防止「添加到主屏幕」升级成原生包后被旧 SW 接管）。
- `src/components/Scanner.tsx` — `../lib/barcode` → `../lib/scan`；隐藏 input 改用 `pickFileFromInput` + `PHOTO_INPUT_PROPS`。
- `src/pages/ProfileScreen.tsx` — `doExport()` 改用 `exportJSON()`，提示文案改为取 `ExportResult.message`。
- `src/pages/LogSheet.tsx` — 3 处拍照 input（主拍照 / 换一张 / 拍包装营养表）统一改用 `pickFileFromInput` + `PHOTO_INPUT_PROPS`。

### 重要约束（后续阶段不要踩）

1. `package.json` **无测试框架、无 lint 脚本**。回归验证只能靠 `typecheck` + `build` +
   临时脚本仿真 + 人工走查。改动前建议先补一份最小回归用例。
2. 云 SDK 内部**独占使用 localStorage** 作为登录态真源（`index.d.cts` 明确写「唯一真源」），
   无法抽象。`kv.ts` 只用于本项目自己写的小状态，别指望它能接管登录态。
3. `lib/barcode.ts` 现在**只被 `lib/scan.ts` 引用**，业务代码已无直接依赖。
   接入 MLKit 时只改 `scan.ts` 里的 `nativeStartScan` / `decodeFromImage` / `warmUpDecoder` 三处。
4. 原生端 endpoint 必须是绝对 HTTPS（iOS ATS）。直连云端后 apikey 请求头属跨域，
   依赖 `CapacitorHttp` 在原生层补发请求绕过 WebView 预检 —— 阶段 2 接入后此处逻辑无需再改。
5. 仓库当前**尚未初始化 git**（`git status` 报 not a repository）。Windows↔Mac mini 同步前需 `git init` 并推到私有仓库。
