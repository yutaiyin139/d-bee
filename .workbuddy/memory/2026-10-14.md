### 环境坑位（本次新踩）

- 本机 HTTP 代理会拦 `curl 127.0.0.1`，必须 `--noproxy '*'`。
- Bash 工具里用 `&` 起的后台进程会在该次调用返回时被杀，**长驻服务必须用
  `run_in_background: true`**，不能用 `cmd &`。
- `agent-browser` 的 element ref（`@eNN`）**只在同一次快照内有效**，跨命令/跨会话必须
  重新 `snapshot -i` 再取 ref；该工具在本机偶发长时间挂起，验收取证优先用
  `open + sleep + screenshot` 的短链，别串长链。
