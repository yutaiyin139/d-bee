## 修复：体重打卡记录按钮在 Android 溢出（17:40-17:46）

用户反馈：Android APK 里「我的」页体重打卡的记录按钮超出卡片范围；**网页版正常**（关键线索）。

**根因**：ProfileScreen.tsx 体重打卡用内联 style 的 `<input type="number">` 是 `flex:1` 但
**缺 `min-width: 0`**。number input 在 Android WebView 里默认最小宽度比桌面浏览器大，flex:1
无法收缩 → 把固定宽度的「记录」按钮挤出卡片。网页版 Chrome 默认 min-width 较小所以正常。
对照：ReportScreen 的体重输入用 `.weight-input input`（styles.css 已含 `min-width:0`）所以正常。

**修复**：ProfileScreen 体重 input 内联 style 加 `minWidth: 0`（一行）。

**验证**：typecheck 0 错、build 成功（主包 hash 变 index-zAU23059.js）。部署远端 200。
APK BUILD SUCCESSFUL 1m47s，归档 `D-Bee-debug-v1.4.0-20261016d.apk`（5.68MB）。

**教训**：flex 布局里 `<input>`（尤其 number/date 类型）必须加 `min-width: 0` 才能收缩，
否则移动端 WebView 默认 min-width 会导致溢出——网页正常≠移动端正常。
